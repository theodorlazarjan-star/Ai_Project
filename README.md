# AI Project – Customer Churn Prediction

## What is it?

A web application that uses machine learning to predict whether a telecom customer is likely to churn.

## Description

The project combines data analysis, machine learning, Flask, HTML and CSS.
Users enter customer information and the application predicts **Churn** or **No Churn**.

## Keywords

Machine Learning, Python, Flask, Customer Churn, Data Science, Data Visualization, HTML, CSS, Classification

## Installation Instructions

1. Clone the repository.
2. Install the required Python packages:

```bash
pip install flask pandas scikit-learn matplotlib seaborn joblib
```

3. Run the application:

```bash
python app.py
```

4. Open:

```text
http://127.0.0.1:5000
```
